

# Ascenda – AI-Powered Virtual Career Assistant

Live Site: https://ascenda-1-cntp.vercel.app/

Ascenda is an AI-driven virtual career assistant built with Next.js that streamlines job search and career development through intelligent tools and personalized insights.



## Ascenda offers:


* **Resume Analyzer** – ATS compliance and weakness detection
* **Interview Preparation** – Mock interviews with feedback
* **Resume & Cover Letter Creator** – Tailored, optimized documents
* **Industry Insights Generator** – Salary data, skills demand, and trends
* **Resource Hub** – Curated materials for career growth

## Competitive Edge

* Personalized AI-driven coaching
* Data-backed suggestions for higher success
* Continuous learning from user interactions

## Target Audience

* Students and fresh graduates
* Mid-career professionals
* Job seekers switching domains or upskilling

## Tech Stack

* **Frontend:** Next.js, Tailwind CSS
* **Backend:** Node.js, Prisma ORM
* **Database:** PostgreSQL (NeonDB)
* **Auth:** Clerk
* **AI/ML:** Gemini APIs

## Project Structure

```
Ascenda/
├── app/              # Next.js app directory  
├── components/       # Reusable React components  
├── hooks/            # Custom React hooks  
├── lib/              # Utility functions  
├── prisma/           # Database schema & config  
├── public/           # Static assets  
├── styles/           # Global styles  
├── .env.local        # Environment variables  
└── next.config.js    # Next.js configuration  
```
